Module 1: Memulai dengan Python

Goal: Memahami fundamental Python, menyiapkan environment development tingkat industri, dan menulis kode pertama.

Chapter 1: Apa itu Python?

Learning Objective

Peserta mampu menjelaskan alasan Python menjadi bahasa utama AI, mengetahui sejarah, filosofi, serta membandingkannya dengan bahasa pemrograman lain secara objektif.

Prerequisite

Mampu menghidupkan komputer dan mengoperasikan sistem operasi (Windows/Mac/Linux).

Introduction

Selamat datang di dunia Python! Sebelum kita menyelam ke dalam kode buatan (*syntax*), kita harus paham dulu alat apa yang sedang kita gunakan. Menjadi AI Engineer bukan hanya soal mengetik kode, tapi tentang memecahkan masalah. Python adalah "palu" yang paling sering digunakan untuk "memaku" algoritma AI modern.

Theory

Sejarah & Filosofi: Python diciptakan oleh Guido van Rossum pada tahun 1991. Berbeda dengan bahasa lama yang kaku, Guido merancang Python dengan filosofi yang terangkum dalam Zen of Python: "Keterbacaan itu penting" (Readability counts) dan "Sederhana lebih baik daripada kompleks".

Kenapa Python untuk AI? AI sangat haus akan perhitungan matematika yang rumit. Python menjadi primadona karena ia menjembatani manusia dan mesin: Sintaksnya sangat mirip bahasa manusia (Inggris), namun ia didukung oleh pustaka (*library*) C/C++ di balik layar yang mampu menghitung triliunan data dalam sekejap.

Visual Explanation

Manusia (Peneliti) ➔ Kode Python (Sederhana) ➔ C++ Engine (Sangat Cepat) ➔ Hardware (GPU/TPU)

Analogy

Bayangkan kamu adalah seorang Event Organizer (EO) yang sedang merencanakan pernikahan megah. Menggunakan bahasa tingkat rendah seperti C++ ibarat kamu harus menjahit sendiri gaun pengantin, merangkai bunga satu per satu, dan memasak katering dari nol. Menggunakan Python ibarat kamu sudah punya asisten MUA, vendor dekorasi, dan katering tepercaya (Library Python); kamu cukup bertindak sebagai Director yang menyatukan konsep acara (logika AI) dengan elegan, dan vendor-vendor tersebut yang akan mengerjakannya dengan cepat.

Syntax & Code Example

Mari kita lihat perbandingan filosofi sintaks (cara penulisan) yang membuktikan kenapa Python sangat disukai.

/* Dalam Bahasa Java (Rumit dan bertele-tele) */
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Halo AI!");
    }
}

# -------------------------------------
# Dalam Bahasa Python (Cukup 1 baris, seperti bahasa manusia!)
print("Halo AI!")

Best Practice

Tanamkan Software Engineering Mindset sejak hari pertama: Jangan gunakan Python untuk membuat game 3D berskala berat atau sistem operasi, karena Python didesain bukan untuk kecepatan eksekusi grafis. Gunakan Python untuk Data, AI, Backend, dan Automasi.

Common Mistakes

Pemula sering mengira Python lebih lambat dari bahasa lain, sehingga enggan mempelajarinya. Faktanya, lambatnya Python tidak relevan di dunia AI, karena komputasi berat (Matrix Multiplication) langsung dioper ke library berbasi C (seperti NumPy) atau langsung ke GPU (CUDA), sementara Python hanya bertugas sebagai 'Remote Control'.

Interactive Exercise

Pikirkan satu aplikasi favorit di *handphone* kamu. Cari tahu di Google: "Apakah [Nama Aplikasi] menggunakan Python?". Kamu akan terkejut bahwa Instagram, Spotify, dan Netflix sangat bergantung pada Python.

Quiz & Coding Challenge

Kuis konsep dan Coding Challenge interaktif untuk *Chapter 1* tersedia di tab Kuis. Kamu tidak akan ditantang menulis kode, melainkan mencocokkan fakta arsitektur Python.

Summary

Python mendominasi AI karena keseimbangan sempurna antara kemudahan baca (sintaks intuitif layaknya bahasa Inggris) dan ekosistem library raksasa (NumPy, PyTorch). Ia ibarat bahasa penghubung (*lingua franca*) antar Data Scientist di seluruh dunia.

What's Next?

Sekarang kamu tahu MENGAPA kita memilih Python. Selanjutnya di Chapter 2, kita akan membangun *Environment Development* lokal di komputermu sendiri agar setara dengan *setup* para insinyur AI di Silicon Valley.

Chapter 2: Instalasi & Environment

Learning Objective

Peserta mampu menginstal Python, mengkonfigurasi Visual Studio Code (VS Code), memahami penggunaan Terminal, dan mengisolasi proyek AI menggunakan Virtual Environment.

(Catatan: Sesuai kurikulum standar, peserta diwajibkan menginstal Python 3.10+ dan Visual Studio Code beserta ekstensi resmi Microsoft Python. Panduan instalasi interaktif dengan ilustrasi lengkap tersedia di Modul Orientasi Platform.)

Analogy: Virtual Environment (venv)

Bayangkan kamu punya rutinitas skincare khusus untuk kulit wajah sensitif dan juga rutinitas haircare khusus untuk rambut rontok. Jika semua botol dicampur berantakan di dalam satu pouch besar, kamu berisiko salah mengoleskan serum rambut ke wajahmu!

Virtual Environment (venv) ibarat memberikan pouch atau rak organizer terpisah untuk masing-masing rutinitas. Di dunia Python, proyek AI (wajah) mungkin butuh Pandas versi 1.0, sementara proyek Web (rambut) butuh versi 2.0. Dengan venv, isi produk (library) antar proyek tidak akan bentrok dan tetap higienis.

Syntax & Code Example

Perintah terminal untuk membuat dan mengaktifkan isolasi lingkungan (*Virtual Environment*):

# 1. Membuat virtual environment bernama "myenv"
python -m venv myenv

# 2. Mengaktifkannya (Windows)
myenv\Scripts\activate

# 2. Mengaktifkannya (Mac/Linux)
source myenv/bin/activate

# 3. Menginstall library dengan pip (Package Installer for Python)
pip install numpy pandas

Best Practice

Jangan pernah menginstal library (seperti TensorFlow atau Django) secara global di komputer (tanpa mengaktifkan venv). Selalu, SELALU buat Virtual Environment setiap kali memulai folder proyek AI baru. Ini adalah standar baku industri (*Software Engineering Fundamental*).

Chapter 3: Program Pertama & Sintaks Dasar

Learning Objective

Peserta mampu menjalankan skrip `.py` pertama, menggunakan fungsi `print()`, menulis dokumentasi lewat komentar, dan memahami hukum indentasi di Python.

Introduction

Semua persiapan sudah selesai. Saatnya menulis mantra sihir pertamamu. Secara tradisi global sejak tahun 1970-an, program pertama yang harus ditulis oleh seorang pemrogram adalah memerintahkan komputer untuk menyapa dunia: "Hello, World!".

Theory & Syntax

print() adalah fungsi bawaan (built-in function) Python yang digunakan untuk menampilkan data (berupa teks maupun angka) ke layar konsol/terminal. Teks yang dicetak harus diapit oleh tanda kutip ganda " atau kutip tunggal '.

Komentar (#) adalah teks yang sepenuhnya diabaikan oleh mesin. Komentar ditulis khusus untuk dibaca oleh MANUSIA (programmer lain atau diri sendiri di masa depan) agar paham apa tujuan baris kode tersebut.

Code Example & Explanation

Di bawah ini adalah Mini Playground. Kamu bisa mengedit kode di dalamnya dan menekan tombol Run untuk melihat hasilnya secara langsung tanpa perlu meninggalkan halaman ini!

hello.py
Terminal Output
Menunggu eksekusi...

Code Explanation: Baris pertama diawali #, sehingga Python melewatinya. Baris kedua memanggil fungsi print untuk memunculkan kalimat di layar. Blok if True: mendemonstrasikan hukum Indentasi. Di Python, kode yang menjorok ke dalam (di-tab atau di-spasi) menandakan bahwa kode tersebut adalah 'anak' atau bagian dari blok kode di atasnya.

Common Mistakes

1. Lupa Tanda Kutip (SyntaxError)

Salah: print(Halo AI)
Benar: print("Halo AI")

2. Indentasi Berantakan (IndentationError)

Jika kamu mencampur spasi dan tombol *Tab* secara tidak konsisten, Python akan langsung crash. VS Code biasanya sudah otomatis menangani ini dengan mengubah 1 Tab menjadi 4 Spasi murni.

Interactive Exercise & Challenge

Buka Tab Latihan sekarang. Buat sebuah file baru bernama sapaan.py di Playground. Cetak namamu, cita-citamu, dan beri komentar di setiap baris kodenya!

Summary

Kamu telah resmi menjadi seorang Python Programmer! Kamu belajar bahwa print() adalah pengeras suara untuk komputermu, bahwa komentar # adalah pesan cinta untuk sesama *developer*, dan bahwa indentasi (spasi menjorok) adalah urat nadi berdirinya hierarki kode Python.
