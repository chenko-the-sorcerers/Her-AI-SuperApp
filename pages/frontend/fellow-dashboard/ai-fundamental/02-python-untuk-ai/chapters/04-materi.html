Chapter 1: Pemrograman Berorientasi Objek (OOP)

Learning Objective

Peserta memahami cara membungkus data dan fungsi ke dalam satu entitas menggunakan paradigma OOP (Object-Oriented Programming).

Analogy

Class ibarat Blueprint atau sketsa desain tas tangan eksklusif di atas kertas. Di sketsa itu tertulis spesifikasinya (Atribut): warna, bahan kulit, dan ukuran. Tertulis juga apa yang bisa dilakukan tas itu (Method): membuka resleting, mengunci magnet.

Object ibarat tas nyata (fisik) yang sudah diproduksi dari sketsa tersebut. Kamu bisa memproduksi ratusan tas berbeda warna, tapi pola jahitannya tetap mengikuti satu sketsa yang sama.

Theory

  • Class: Cetakan atau templat. (Contoh: `class Tas:`)
  • Object: Hasil cetakan atau perwujudan nyata. (Contoh: `tas_aku = Tas()`)
  • Attribute: Ciri-ciri atau variabel yang nempel di objek. (Contoh: `warna = "Pink"`)
  • Method: Tindakan atau fungsi yang nempel di objek. (Contoh: `def buka_resleting(self):`)
  • __init__: Fungsi ajaib yang selalu otomatis dipanggil saat sebuah tas baru diproduksi dari pabrik.

Chapter 2: Persiapan Rencana B (Error Handling)

Learning Objective

Peserta mampu memprediksi masalah di program dan membuat rencana cadangan agar program tidak berhenti tiba-tiba (crash).

Analogy

Menulis kode tanpa Error Handling ibarat mengadakan pesta kebun outdoor yang sangat megah tanpa menyiapkan tenda (Plan B). Begitu hujan turun mendadak (Error), seluruh pesta bubar dan berantakan (Crash).

Konsep Try-Except adalah tenda cadangannya. Try: "Coba kita gelar pestanya di kebun". Except: "Kalau tiba-tiba hujan, alihkan tamu masuk ke dalam gedung, acaranya tetap lanjut!"

Syntax & Code Example

Contoh masalah paling umum adalah mencoba membagi angka dengan nol, atau mencoba membuka file Excel yang ternyata terhapus. Tanpa Try-Except, Python akan langsung ngambek dan crash.

Chapter 3: Buku Tamu Digital (File I/O)

Learning Objective

Peserta mampu membaca data dari sebuah file teks dan menyimpan hasil pemrosesan AI kembali ke dalam file menggunakan fungsi open().

Analogy

Membaca dan menulis file (I/O) ibarat menjaga meja penerima tamu di sebuah acara. Saat tamu datang, kamu membaca daftar undangan (File Read). Saat tamu menyerahkan kado, kamu menulis namanya di buku tanda terima kado (File Write). Begitulah cara AI berinteraksi dengan dunia luar: mengambil dataset, lalu mencetak laporan.

Syntax & Code Example

Kita menggunakan fungsi bawaan open() dengan mode "r" untuk Read (membaca) dan mode "w" untuk Write (menulis/menimpa).
