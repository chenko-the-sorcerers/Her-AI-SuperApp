Chapter 1: Kalkulator Massal (NumPy)

Learning Objective

Peserta memahami bagaimana NumPy digunakan untuk melakukan perhitungan matematika kompleks pada ribuan data sekaligus tanpa perlu perulangan (loop) manual.

Analogy

Bayangkan kamu adalah kasir di minimarket. Jika pakai List Python biasa, kamu harus men-scan dan menghitung total harga barang satu per satu (menggunakan Loop).

Dengan NumPy, ibarat kamu punya scanner keranjang pintar: Cukup letakkan sekeranjang penuh barang, dan NumPy akan mengalikan semua jumlah barang dengan harga diskonnya secara serentak dalam 1 detik! (Komputasi Vektorisasi).

Chapter 2: Excel Super Canggih (Pandas)

Learning Objective

Peserta memahami apa itu DataFrame di Pandas dan bagaimana Pandas digunakan untuk menganalisis data dalam format baris dan kolom persis seperti Microsoft Excel.

Analogy

NumPy ahli dalam menghitung angka murni, tapi kurang ramah kalau kita punya data campur aduk (ada teks nama orang, ada angka umur, ada uang). Di sinilah Pandas masuk!

Pandas DataFrame ibarat spreadsheet (lembar kerja) Excel yang super canggih. Kamu bisa menyaring (filter), mengelompokkan (group), dan membersihkan data kosong dalam sekejap mata lewat kode.

Syntax & Code Example

Chapter 3: Membaca Dataset CSV

Theory & Practical Use

Di dunia AI sungguhan, kita hampir tidak pernah mengetik data manual seperti contoh di atas. Data Scientist biasanya mengunduh file CSV (Comma Separated Values) yang berisi jutaan baris data, lalu memintanya dibaca oleh Pandas.

Fungsi sakti yang digunakan adalah pd.read_csv("nama_file.csv").

Contoh pseudocode di dunia nyata:

import pandas as pd

# Membaca data penjualan e-commerce selama 5 tahun
dataset_penjualan = pd.read_csv("penjualan_sepatu_2020_2025.csv")

# Menampilkan 5 baris pertama untuk ngintip datanya
print(dataset_penjualan.head())
