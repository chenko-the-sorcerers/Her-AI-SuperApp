Roadmap Kurikulum Python untuk AI

Kurikulum ini dirancang berjenjang dari sintaks dasar hingga Object-Oriented Programming, memastikan penguasaan komprehensif standar industri. Terdiri dari 5 fase utama:

  • Fase 1: Fondasi Dasar (Sintaks & Tipe Data)
  • Fase 2: Koleksi & Alur Logika (Struktur Data & Control Flow)
  • Fase 3: Modularitas & Efisiensi (Function & Generator)
  • Fase 4: Arsitektur & I/O (OOP & Error Handling)
  • Fase 5: Ekosistem Data Science (NumPy, Pandas)

Fase 1: Fondasi Dasar

Memahami alasan penggunaan Python serta tipe data pembangun utamanya.

1. Kenapa Python?

Python adalah bahasa pemrograman yang paling dominan di dunia Artificial Intelligence dan Data Science. Kemudahan sintaks, ekosistem library yang kaya, dan komunitas global yang aktif menjadikannya pilihan utama peneliti dan praktisi AI.

Beberapa alasan Python menjadi standar di industri AI:

Sintaks Sederhana

Kode Python mudah dibaca dan ditulis, memungkinkan fokus pada logika AI alih-alih kompleksitas bahasa.

Ekosistem Library

NumPy, Pandas, scikit-learn, PyTorch, dan TensorFlow menyediakan fondasi siap pakai untuk seluruh pipeline AI.

Komunitas Global

Jutaan developer berbagi tutorial, model, dan dataset. Hampir semua riset AI terkini dipublikasikan dengan kode Python.

2. Variabel & Tipe Data Dasar

Python memiliki beberapa tipe data fundamental yang wajib dipahami sebelum mulai membangun model AI:

Integer & Float

int untuk bilangan bulat (42, -7) dan float untuk bilangan desimal (3.14, 1.0). Digunakan dalam perhitungan bobot model, learning rate, dan dimensi data.

String

str untuk teks ("hello", 'AI'). Penting dalam NLP untuk preprocessing teks, tokenization, dan representasi kata.

Boolean

bool hanya bernilai True atau False. Digunakan untuk kontrol logika, filter data, dan evaluasi kondisi model.

nama = "Aisyah"         # string
umur = 25                 # integer
tinggi = 1.65              # float
aktif = True              # boolean

print(type(nama))     # <class 'str'>
print(type(umur))     # <class 'int'>

Fase 2: Koleksi & Alur Logika

Mengelola himpunan data dan mengatur logika pengambilan keputusan.

3. Struktur Data

Empat struktur data paling penting yang akan terus digunakan dalam workflow AI:

List

Koleksi terurut dan mutable. [1, 2, 3]. Operasi umum: append(), [start:end] slicing, list comprehension. Menyimpan batch data pelatihan.

Tuple

Koleksi terurut dan immutable. (1, 2, 3). Digunakan untuk koordinat, dimensi tensor, dan data yang tidak boleh berubah.

Dictionary

Pasangan key-value. {"nama": "Aisyah", "skor": 85}. Hyperparameter model, konfigurasi training, mapping label.

Set

Koleksi unique dan tidak terurut. {1, 2, 3}. Menghapus duplikat data, operasi himpunan, unique vocabulary.

# List — untuk batch data
skor = [78, 85, 92, 64, 88]
terbaik = [s for s in skor if s > 80]    # [85, 92, 88]

# Tuple — untuk data tetap
koordinat = (106.8, -6.2)    # longitude, latitude

# Dictionary — untuk konfigurasi
model = {"lr": 0.01, "epochs": 50, "batch": 32}

# Set — untuk unique values
label = {"kucing", "anjing", "burung"}

4. Control Flow

Kontrol alur adalah fondasi untuk logika preprocessing, evaluasi model, dan decision-making dalam pipeline AI:

# Percabangan — filter data
akurasi = 0.87
if akurasi > 0.8:
    print("Model siap deploy")
elif akurasi > 0.6:
    print("Perlu tuning")
else:
    print("Evaluasi ulang data")

# Loop — iterasi dataset
dataset = [10, 20, 30, 40]
for i, data in enumerate(dataset):
    print(f"Batch {i}: {data * 2}")

# While — training loop
epoch = 0
while epoch < 10:
    print(f"Training epoch {epoch}...")
    epoch += 1

Fase 3: Modularitas & Efisiensi

Membungkus kode menjadi blok *reusable* dan menulis sintaks iterasi secara *Pythonic*.

5. Functions

Fungsi adalah blok kode reusable yang menjadi unit dasar pipeline AI — dari preprocessing hingga evaluasi:

def hitung_rata(data):
    """Menghitung rata-rata dari list angka."""
    return sum(data) / len(data)

# Fungsi dengan parameter default
def normalisasi(nilai, min_val=0, max_val=1):
    return (nilai - min_val) / (max_val - min_val)

# Lambda — fungsi satu baris
kuadrat = lambda x: x ** 2
print(kuadrat(5))   # 25

# Pemakaian
skor = [78, 85, 92, 64, 88]
print(hitung_rata(skor))   # 81.4

6. List Comprehension & Generator

Fitur pythonic untuk membuat list atau iterator dengan sintaks elegan. Sangat berguna di Data Science untuk preprocessing data yang cepat dan menghemat memori.

# List Comprehension biasa
kuadrat = [x**2 for x in range(10)]

# Dictionary Comprehension
skor_dict = {f"Siswa_{i}": i*10 for i in range(3)}

# Generator Expression (Lazy evaluation, memori hemat untuk dataset AI)
gen_big = (x**2 for x in range(1000000)) # Tidak butuh RAM besar
print(next(gen_big)) # 0
print(next(gen_big)) # 1

Fase 4: Arsitektur & I/O

Membangun kerangka AI dengan Class (OOP) dan menangani operasi sistem seperti File I/O dan Error Handling.

7. Object-Oriented Programming (OOP)

Memahami Class dan Object sangat krusial, terutama ketika mendesain custom model Deep Learning di framework modern seperti PyTorch.

class ModelAI:
    def __init__(self, layers):
        self.layers = layers
        self.trained = False

    def train(self, data):
        print(f"Training model {self.layers} layer...")
        self.trained = True

    def predict(self):
        if not self.trained:
            return "Belum ditraining!"
        return "Prediksi selesai."

# Inisiasi Objek
model_cv = ModelAI(layers=5)
model_cv.train("data_gambar")

8. Error Handling & File I/O

Mengelola exception dengan try...except agar program tidak crash saat memproses jutaan data, serta membaca/menulis file dataset.

# Error Handling aman untuk loop data
try:
    hasil = 10 / 0
except ZeroDivisionError:
    print("Error: Tidak bisa dibagi nol!")

# Context Manager untuk File I/O (otomatis tutup file)
import json

data_dict = {"label": "Positif", "teks": "AI hebat!"}
with open("dataset.json", "w") as f:
    json.dump(data_dict, f)

Fase 5: Ekosistem Data Science

Mengenal library fundamental yang di-import pada awal setiap file proyek AI.

9. Library Penting untuk AI

Tiga library foundational yang membangun seluruh ekosistem AI Python:

NumPy

Komputasi numerik dengan array multidimensi. Operasi matriks, aljabar linear, transformasi data — fondasi untuk semua library AI lainnya.

Pandas

Manipulasi data tabular dengan DataFrame. Loading CSV, cleaning, aggregation, join — 80% waktu data scientist dihabiskan di sini.

Matplotlib

Visualisasi data dan hasil model. Plot training loss, distribusi data, confusion matrix — komunikasi hasil ke stakeholder.

import numpy as np
import pandas as pd

# NumPy — array & operasi vektor
data = np.array([[1, 2, 3], [4, 5, 6]])
print(data.shape)           # (2, 3)
print(data.mean(axis=0))    # [2.5 3.5 4.5]

# Pandas — DataFrame
df = pd.DataFrame({
    'nama': ['Alya', 'Budi', 'Cici'],
    'skor': [85, 72, 91]
})
print(df[df['skor'] > 80])   # Filter peserta skor > 80
