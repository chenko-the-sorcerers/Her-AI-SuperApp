Chapter 02

Supervised Learning & Model Hypothesis

Supervised learning bekerja dengan pasangan input dan label. Tujuannya mencari fungsi prediksi yang cukup akurat untuk data baru.

Notation

Dari data ke hipotesis h(x)

Notasi ini membantu kita membaca hampir semua algoritma supervised learning.

x Feature vector

Daftar nilai fitur untuk satu contoh, misalnya [durasi belajar, nilai latihan, jumlah login].

y Label

Jawaban benar pada data latih, misalnya lulus tepat waktu atau tidak.

h(x) Hypothesis

Fungsi prediksi yang dipilih model setelah training.

Model Components

Model, parameter, loss, dan optimisasi

Setiap algoritma supervised learning punya empat bagian yang saling terhubung.

Model dan hypothesis space

Model menentukan keluarga fungsi yang boleh dicari. Hypothesis space adalah semua kandidat fungsi dalam keluarga tersebut.

Parameter

Nilai internal yang diubah saat training, misalnya bobot w dan bias b pada model linear.

Loss

Ukuran kesalahan prediksi. Training berusaha membuat loss sekecil mungkin pada data latih.

Optimisasi

Proses mencari parameter yang menurunkan loss, misalnya gradient descent.

Algorithms

Regresi, klasifikasi, k-NN, dan decision tree

Linear Regression

Memprediksi nilai numerik. Contoh: harga rumah, estimasi durasi belajar, skor ujian.

y hat = w*x + b

Classification

Memprediksi kelas. Contoh: spam atau bukan spam, lulus atau belum lulus.

P(class | x)

k-NN

Melihat tetangga terdekat. Intuisinya: data yang mirip cenderung punya label mirip.

vote(k nearest)

Decision Tree

Membuat keputusan bertahap berdasarkan split fitur. Mudah dijelaskan, tetapi bisa overfit.

if feature > threshold
Visual Mental Model

Training mencari garis, batas, atau aturan terbaik

Batas keputusan

Untuk klasifikasi, model mencari batas yang memisahkan kelas. Untuk regresi, model mencari garis atau kurva yang mendekati nilai target.

  • Model terlalu sederhana dapat underfit.
  • Model terlalu fleksibel dapat overfit.
  • Data baru adalah ujian sebenarnya.
Model Families

Generative vs discriminative

Generative

Mencoba memahami bagaimana data dan kelas terbentuk. Bisa memodelkan distribusi data.

Contoh ringan: Naive Bayes.

Discriminative

Fokus langsung pada batas prediksi atau peluang kelas berdasarkan input.

Contoh ringan: Logistic regression, SVM.

Inti chapter ini

Algoritma ML bukan sihir. Ia memilih satu fungsi dari ruang kemungkinan, mengukur error dengan loss, lalu mengubah parameter sampai prediksi membaik.
