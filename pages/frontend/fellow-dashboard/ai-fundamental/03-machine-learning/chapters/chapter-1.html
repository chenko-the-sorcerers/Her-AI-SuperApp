Chapter 01

Foundations of Machine Learning

Machine Learning adalah cara membuat sistem yang belajar dari contoh data, bukan hanya menjalankan aturan yang ditulis manual.

Rule-based

Programmer menulis aturan eksplisit. Cocok jika aturan stabil, sedikit, dan mudah diuji.

if nilai >= 75: lulus

Machine Learning

Model menemukan pola dari contoh. Cocok saat aturan sulit ditulis, pola berubah, dan data tersedia.

model.fit(data, label)
Core Idea

Belajar dari data

Dalam ML, kita menyediakan pengalaman berupa data. Model mencari pola, lalu memakai pola itu untuk memprediksi data baru.

Data Contoh historis yang berisi fitur dan, jika supervised, label.
Training Model menyesuaikan parameter agar error prediksi turun.
Inference Model terlatih memberi prediksi untuk contoh baru.
Vocabulary

Dataset, fitur, label, dan target

Istilah ini akan muncul terus di supervised learning, evaluasi, dan latihan.

Istilah Makna Contoh kelulusan peserta
Dataset Kumpulan baris data yang dipakai untuk belajar. Riwayat progres peserta fellowship.
Fitur Sinyal input yang menjelaskan tiap contoh. Jumlah login, nilai latihan, waktu belajar.
Label Jawaban benar pada data latih. Lulus tepat waktu atau tidak.
Target Nilai yang ingin diprediksi. Status kelulusan peserta baru.
Train/Test Pemisahan data untuk belajar dan mengecek generalisasi. Data cohort lama untuk train, cohort baru untuk test.
Paradigms

Tiga cara utama model belajar

Perbedaannya ada pada sinyal belajar yang tersedia.

Supervised Learning

Data memiliki label. Model belajar memetakan x ke y.

Spam detection, prediksi kelulusan, harga rumah.

Unsupervised Learning

Tidak ada label. Model mencari struktur, cluster, atau representasi.

Segmentasi pengguna, clustering transaksi, PCA.

Reinforcement Learning

Agen belajar dari aksi, state, reward, dan penalti.

Game AI, robot navigasi, strategi rekomendasi.
Examples

Kasus nyata yang mudah dibayangkan

Kelulusan

Prediksi peserta yang butuh bantuan lebih awal berdasarkan progres, latihan, dan aktivitas diskusi.

Spam

Model membaca pola kata, link, pengirim, dan perilaku email yang berubah dari waktu ke waktu.

Rekomendasi

Sistem menyarankan konten berdasarkan histori, kemiripan pengguna, dan konteks saat ini.

Kapan ML tidak perlu digunakan?

Jika aturan bisnis sudah jelas, data terlalu sedikit, biaya salah prediksi terlalu tinggi tanpa pengawasan manusia, atau solusi sederhana lebih transparan dan mudah dirawat, gunakan rule-based atau analisis manual dulu.
