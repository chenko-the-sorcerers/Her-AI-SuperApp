Fungsi dan Parameter

Membungkus logika menjadi unit reusable untuk pipeline AI.

Tujuan Chapter

Peserta mampu mendesain fungsi modular dengan parameter wajib, parameter opsional, keyword argument, dan nilai kembalian sehingga kode AI tidak berubah menjadi satu blok besar yang sulit dirawat.

Kenapa Topik Ini Penting untuk AI

Pipeline AI biasanya terdiri dari banyak tahap: membaca data, membersihkan teks, normalisasi angka, menghitung metrik, menyimpan laporan, dan menjalankan evaluasi. Tanpa fungsi, semua tahap bercampur dan sulit diuji. Fungsi membuat pipeline dapat dipecah menjadi unit kecil yang bisa dipakai ulang.

Konsep Utama

Fungsi dideklarasikan dengan def. Parameter adalah nama input di definisi fungsi, sedangkan argument adalah nilai yang dikirim saat fungsi dipanggil. return mengirim nilai keluar dari fungsi agar bisa dipakai lagi. print() hanya menampilkan nilai ke terminal.

Analogi

Fungsi seperti mesin blender. Buah yang masuk adalah parameter, tombol kecepatan adalah parameter opsional, dan jus yang keluar adalah return value. Kalau mesin hanya berkata "jus selesai" tanpa mengeluarkan jus, bagian dapur berikutnya tidak bisa memakainya.

Contoh Kode Utama

def hitung_akurasi(benar, total):
    return benar / total

hasil = hitung_akurasi(80, 100)
print(hasil)

Penjelasan: fungsi menerima dua input, menghitung pembagian, lalu mengembalikan nilai 0.8. Nilai itu disimpan di variabel hasil dan dapat dipakai operasi berikutnya.

Contoh Tambahan

1. Parameter default

def sapa_user(nama, peran="Fellow"):
    return f"Halo {nama}, peran Anda adalah {peran}"

print(sapa_user("Rara"))
print(sapa_user("Nadia", peran="Mentor"))

2. Return beberapa nilai

def kalkulasi_min_max(list_angka):
    return min(list_angka), max(list_angka)

terendah, tertinggi = kalkulasi_min_max([7, 2, 9, 4])
print(terendah, tertinggi)

3. Fungsi preprocessing kecil

def bersihkan_teks(teks):
    teks = teks.lower().strip()
    teks = " ".join(teks.split())
    return teks

print(bersihkan_teks("  Belajar   Python Untuk AI  "))

Common Mistakes

  1. Lupa return, sehingga hasil fungsi menjadi None.
  2. Mengira print() sama dengan return.
  3. Mengakses variabel lokal fungsi dari luar fungsi.
  4. Menaruh parameter default sebelum parameter wajib.

Best Practices

  1. Buat fungsi melakukan satu tugas spesifik.
  2. Gunakan nama fungsi berbentuk kata kerja, seperti bersihkan_teks atau hitung_loss.
  3. Gunakan docstring untuk fungsi penting.
  4. Gunakan keyword argument saat pemanggilan mulai banyak parameter.

Latihan Kecil

Buat fungsi normalisasi_skala(nilai, maksimum=100) yang mengembalikan nilai dibagi maksimum.

def normalisasi_skala(nilai, maksimum=100):
    return nilai / maksimum

print(normalisasi_skala(75))
print(normalisasi_skala(30, maksimum=60))

Ringkasan Chapter

Fungsi adalah fondasi modularitas. Dengan parameter dan return, kode Python dapat dirangkai menjadi pipeline AI yang bersih, reusable, dan mudah diuji.
