Pandas dan Tabular Data

Fondasi manipulasi data tabel untuk membaca dataset, inspeksi awal, filter, dan ringkasan statistik sebelum masuk ke machine learning.

Tujuan Chapter

Peserta memahami struktur Series dan DataFrame, mampu membuat DataFrame dari dictionary, membaca dataset CSV, melakukan inspeksi awal, memilih kolom, dan memfilter baris berdasarkan kondisi.

Kenapa Topik Ini Penting untuk AI

Sebagian besar waktu proyek AI tidak habis untuk membuat model, tetapi untuk menyiapkan data. Data sering datang sebagai tabel: CSV pendaftaran, log transaksi, hasil survei, metadata gambar, label sentimen, atau catatan sensor. Pandas memberi alat untuk membaca, memeriksa, membersihkan, dan memfilter data semacam itu secara sistematis.

Konsep Utama

Series adalah struktur satu dimensi seperti satu kolom tabel. DataFrame adalah struktur dua dimensi seperti spreadsheet: ada baris, kolom, nama kolom, dan indeks.

DataFrame dapat dibuat dari dictionary, dibaca dari CSV dengan pd.read_csv(), diperiksa dengan .head(), diringkas dengan .info() dan .describe(), lalu difilter memakai boolean masking.

Pandas dibangun di atas NumPy, tetapi lebih cocok untuk data dunia nyata yang heterogen: ada teks, angka, boolean, kategori, dan tanggal dalam satu tabel.

Analogi

Jika NumPy adalah kalkulator matriks super cepat, Pandas adalah Excel di dalam Python. Bedanya, Pandas bisa diprogram, diulang, diaudit, dan digabung dengan pipeline AI. Filter yang biasanya diklik manual di spreadsheet bisa ditulis sebagai kode yang konsisten.

Contoh Kode Utama: Membuat dan Memfilter DataFrame

import pandas as pd

data = {
    "Nama": ["Aisyah", "Budi", "Citra"],
    "Skor": [92, 75, 88],
    "Aktif": [True, False, True]
}

df = pd.DataFrame(data)
lulus = df[df["Skor"] >= 85]

print("Data lengkap:")
print(df)
print("
Peserta skor >= 85:")
print(lulus)

Penjelasan: dictionary berisi nama kolom dan list nilai. Pandas mengubahnya menjadi DataFrame. Ekspresi df["Skor"] >= 85 menghasilkan mask boolean, lalu mask itu dipakai untuk memilih baris yang lulus.

Contoh Tambahan 1: Statistik Deskriptif

import pandas as pd

data_skor = {"Nilai": [80, 90, 75, 85, 95]}
df_skor = pd.DataFrame(data_skor)

print(df_skor.describe())

.describe() menghitung count, mean, std, min, kuartil, dan max untuk kolom numerik. Ini membantu membaca karakter awal dataset.

Contoh Tambahan 2: Rata-rata Kolom

import pandas as pd

data_loss = {"loss": [0.4, 0.2, 0.1]}
df_loss = pd.DataFrame(data_loss)
mean_loss = df_loss["loss"].mean()

print(mean_loss)

Kolom loss diakses sebagai Series, lalu method .mean() menghitung rata-rata.

Contoh Tambahan 3: Simulasi Membaca CSV

import pandas as pd
from io import StringIO

csv_text = """model,akurasi,status
A,0.85,aktif
B,0.72,aktif
C,0.91,arsip
"""

df_csv = pd.read_csv(StringIO(csv_text))
aktif_bagus = df_csv[(df_csv["akurasi"] > 0.80) & (df_csv["status"] == "aktif")]

print(df_csv.head())
print("
Model aktif dengan akurasi bagus:")
print(aktif_bagus)

Di proyek nyata, pd.read_csv("dataset.csv") membaca file fisik. Di contoh browser, StringIO membuat CSV tiruan agar kode tetap bisa dijalankan tanpa file eksternal.

Common Mistakes

  1. Salah menulis nama kolom sehingga muncul KeyError.
  2. Memakai and untuk filter Pandas. Gunakan & dan bungkus tiap kondisi dengan tanda kurung.
  3. Mengira semua operasi otomatis mengubah DataFrame asal. Banyak operasi mengembalikan DataFrame baru.
  4. Tidak mengecek missing values dan tipe data sebelum analisis.

Best Practices

  1. Gunakan alias standar import pandas as pd.
  2. Jalankan df.head(), df.info(), dan df.describe() saat menerima dataset baru.
  3. Simpan hasil filter ke variabel baru agar transformasi mudah dilacak.
  4. Gunakan nama kolom yang jelas dan konsisten.

Latihan Kecil

Buat DataFrame berisi model A, B, C dengan akurasi 0.85, 0.72, 0.91. Filter hanya model dengan akurasi di atas 0.80.

import pandas as pd

data_ai = {
    "Model": ["A", "B", "C"],
    "Akurasi": [0.85, 0.72, 0.91]
}

df_ai = pd.DataFrame(data_ai)
filter_df = df_ai[df_ai["Akurasi"] > 0.80]
print(filter_df)
