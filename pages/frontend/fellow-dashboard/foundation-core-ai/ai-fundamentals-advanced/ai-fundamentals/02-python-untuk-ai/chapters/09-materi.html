Object-Oriented Programming Dasar

Class, object, self, method, dan inheritance untuk membaca arsitektur library AI.

Tujuan Chapter

Peserta memahami class, object, attribute, method, constructor __init__, self, dan inheritance dasar sebagai fondasi membaca library AI modern.

Kenapa Topik Ini Penting untuk AI

Library machine learning banyak memakai OOP. Di scikit-learn, model dibuat sebagai object lalu dipanggil dengan .fit() dan .predict(). Di PyTorch, model neural network ditulis sebagai class turunan torch.nn.Module. Memahami OOP membuat dokumentasi framework AI jauh lebih mudah dibaca.

Konsep Utama

Class adalah blueprint. Object adalah instance nyata dari blueprint tersebut. Attribute adalah data yang menempel pada object. Method adalah fungsi yang menempel pada object. self menunjuk ke object aktif yang sedang memakai method.

Analogi

Class seperti cetak biru rumah. Object adalah rumah fisik yang dibangun dari cetak biru. Dari satu blueprint, kita bisa membuat banyak rumah dengan warna, pemilik, atau isi yang berbeda.

Contoh Kode Utama

class Model:
    def __init__(self, nama):
        self.nama = nama

    def info(self):
        return f"Model aktif: {self.nama}"

model = Model("SentimentAnalyzer")
print(model.info())

Penjelasan: Model adalah class. Saat object dibuat, __init__ menyimpan nama ke self.nama. Method info() membaca attribute tersebut dan mengembalikan teks.

Contoh Tambahan

1. Inheritance sederhana

class Model:
    def __init__(self, nama):
        self.nama = nama

class JaringanSaraf(Model):
    def latih(self):
        return f"Melatih model: {self.nama}"

nn = JaringanSaraf("MultiLayerPerceptron")
print(nn.latih())

2. Representasi string object

class Metrik:
    def __init__(self, nama, skor):
        self.nama = nama
        self.skor = skor

    def __str__(self):
        return f"Metrik {self.nama}: {self.skor}"

m = Metrik("Akurasi", 0.95)
print(m)

3. Class dataset mini

class DatasetMini:
    def __init__(self, data):
        self.data = data

    def jumlah_baris(self):
        return len(self.data)

    def kosong(self):
        return len(self.data) == 0

ds = DatasetMini([10, 20, 30])
print(ds.jumlah_baris())
print(ds.kosong())

Common Mistakes

  1. Lupa menulis self sebagai parameter pertama method.
  2. Mengira attribute object satu otomatis memengaruhi object lain.
  3. Membuat satu class raksasa yang mengurus semua hal.
  4. Lupa memanggil super().__init__() saat class anak punya constructor sendiri.

Best Practices

  1. Gunakan PascalCase untuk nama class.
  2. Jaga class tetap punya tanggung jawab tunggal.
  3. Gunakan method untuk perilaku yang benar-benar terkait object.
  4. Baca dokumentasi AI dengan pola: buat object, latih, prediksi, evaluasi.

Latihan Kecil

Buat class Tokenizer yang menerima list vocab dan method is_known(kata).

class Tokenizer:
    def __init__(self, vocab):
        self.vocab = vocab

    def is_known(self, kata):
        return kata in self.vocab

tok = Tokenizer(["ai", "deep", "learning"])
print(tok.is_known("deep"))
print(tok.is_known("python"))
