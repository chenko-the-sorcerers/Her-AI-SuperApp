Operasi File I/O

Materi final Pemrograman Python untuk AI disajikan lengkap, rinci, dan bertahap dari fondasi bahasa sampai pintu gerbang data science.

Tujuan Chapter

Peserta mampu melakukan interaksi baca-tulis dokumen fisik pada format teks secara aman menggunakan manajer konteks, serta memahami cara kerja navigasi direktori berkas.

Konsep Utama

Operasi File I/O memungkinkan penyimpanan dan pembacaan data secara persisten ke dalam cakram keras. Penggunaan struktur with menjamin berkas ditutup otomatis oleh sistem demi mencegah terjadinya penguncian data.

Analogi

Bayangkan membaca berkas seperti Mengambil Buku dari Lemari Arsip Terkunci. Langkah konvensionalnya adalah: Anda mengambil kunci, membuka pintu lemari, mengambil dokumen, membaca isinya, lalu Anda wajib mengunci kembali pintu lemari tersebut dan menyimpan kuncinya. Jika Anda lupa mengunci kembali lemari (atau terjadi kecelakaan di tengah jalan saat Anda membaca), lemari akan tetap terbuka selamanya, berisiko dirusak orang lain atau file terkunci. Penggunaan manajer konteks with bertindak seperti Petugas Arsip Otomatis yang mendampingi Anda: ia membukakan lemari, dan begitu selesai membaca atau pergi dari meja, ia langsung mengunci kembali lemari tersebut secara instan tanpa perlu Anda ingat.

Penjelasan Teori Rinci

Sejauh ini, semua variabel dan objek data yang kita buat hanya disimpan di dalam memori akses acak komputer. Saat program mati atau komputer dimatikan, semua data tersebut akan langsung hilang. Operasi File I/O memungkinkan kita untuk membaca data masukan dari media penyimpanan non-volatile dan menyimpan hasil pemrosesan program secara permanen.
Dalam Python, untuk berinteraksi dengan berkas, kita menggunakan fungsi bawaan open(file, mode). Parameter mode menentukan jenis interaksi yang diizinkan 6:

  • "r" (Read): Membuka berkas hanya untuk dibaca. Jika berkas tidak eksis di direktori tujuan, akan muncul eror FileNotFoundError.
  • "w" (Write): Membuka berkas untuk ditulis. Jika berkas belum ada, berkas baru akan dibuat secara otomatis. Jika berkas sudah ada, seluruh isi lamanya akan dihapus total (ditimpa).
  • "a" (Append): Membuka berkas untuk ditulis, namun isinya tidak dihapus. Data baru yang kita tulis akan ditambahkan di baris paling akhir dari isi berkas lama.

Masalah terbesar bagi pemula saat menulis kode File I/O adalah lupa menutup koneksi berkas menggunakan fungsi .close() setelah operasi selesai. Hal ini dapat menyebabkan penggunaan sumber daya memori yang tidak efisien, mencegah proses lain untuk memodifikasi berkas tersebut, atau bahkan kehilangan data yang belum sempat dikirim dari buffer ke cakram keras.
Untuk mengatasi risiko tersebut, Python menyediakan protokol manajer konteks yang ditandai dengan kata kunci with. Ketika blok with open(...) as f: dibuat, Python akan mendirikan batas eksekusi aman. Begitu program keluar dari blok indentasi with tersebut, Python secara otomatis akan memanggil fungsi .close() di balik layar untuk melepas berkas kembali ke sistem operasi.

Alur Manajer Konteks WITH:
with open("data.txt", "r") as f:

Masuk Blok Indentasi
(Operasi Baca File)
|
Apakah Keluar Blok (Atau Terjadi Eror)?
|
+-------v-------+
| Sistem AUTO- |
| CLOSE Berkas |

Contoh Kode Utama

with open("log.txt", "w") as f:
    f.write("Akurasi: 0.95")

Penjelasan Kode Baris demi Baris

  • Baris 1: with open("log.txt", "w") as f: Menggunakan manajer konteks with untuk membuka berkas bernama "log.txt" dalam mode menulis "w".6 Objek berkas dirujuk dengan variabel penunjuk alias f.
  • Baris 2: f.write("Akurasi: 0.95") Memanggil metode .write() milik objek berkas untuk merekam string "Akurasi: 0.95" ke dalam berkas fisik di hard disk. Setelah baris ini selesai, Python secara otomatis menutup berkas.

3 Contoh Tambahan

  1. Membaca seluruh konten berkas sekaligus 6:

       with open("log.txt", "r") as f:
   isi = f.read()
   print(isi)

Penjelasan baris demi baris:
* Baris 1: with open(...) membuka berkas log dalam mode membaca "r".6
* Baris 2: isi = f.read() memanggil metode .read() untuk menyedot seluruh konten teks berkas menjadi satu string tunggal.
* Baris 3: print(isi) mencetak isi berkas tersebut.
2. Membaca berkas baris demi baris secara efisien menggunakan perulangan 6:

   with open("log.txt", "r") as f:
       for baris in f:
           print(baris.strip())

Penjelasan baris demi baris:
* Baris 1: with open(...) membuka berkas log untuk dibaca.
* Baris 2: for baris in f: memanfaatkan sifat iterable dari objek berkas untuk membaca baris demi baris secara malas, sangat hemat memori RAM.
* Baris 3: print(baris.strip()) mencetak baris dengan membuang karakter spasi atau baris baru di ujung teks menggunakan .strip().
3. Menambahkan baris teks baru tanpa menghapus isi lama menggunakan mode "a" 6:

   with open("log.txt", "a") as f:
       f.write("\\nEpoch berikutnya selesai")

Penjelasan baris demi baris:
* Baris 1: with open(...) membuka berkas dengan mode "a" (Append).
* Baris 2: f.write(...) menulis teks tambahan di bagian paling akhir berkas log fisik.

3 Common Mistakes

  1. Lupa Menggunakan Manajer Konteks with: Membuka berkas dengan penulisan lama f = open("file.txt") dan lupa memanggil f.close(). Akibatnya, berkas terkunci oleh sistem operasi.
  2. Menggunakan Mode "w" Saat Ingin Menambah Data: Salah memilih mode tulis, berniat ingin menambahkan data baru namun menggunakan mode "w" alih-alih "a". Ini mengakibatkan seluruh data riwayat lama Anda di dalam berkas terhapus bersih secara permanen.
  3. Kesalahan Lokasi Berkas: Mencoba membaca berkas dengan nama relatif tanpa menyadari bahwa terminal aktif berada di direktori yang berbeda, sehingga memicu FileNotFoundError. Selalu pastikan path lokasi berkas dirujuk secara tepat.

3 Best Practices

  1. Selalu gunakan struktur manajer konteks with open(...) untuk menjamin keamanan penutupan berkas secara otomatis.
  2. Tentukan parameter penyandian karakter secara eksplisit saat membuka berkas teks, contoh: open("data.txt", "r", encoding="utf-8"), untuk menghindari masalah eror pembacaan karakter non-ASCII di sistem operasi yang berbeda.
  3. Untuk penanganan jalur berkas yang tangguh lintas sistem operasi, gunakan modul pustaka standar pathlib bawaan Python.

Hubungan Konsep Ini dengan AI/Data Science

Operasi File I/O adalah gerbang masuk pertama bagi model kecerdasan buatan. Dalam pemrosesan bahasa alami, dataset teks mentah seperti ulasan pelanggan, dokumen PDF hukum, atau percakapan obrolan tersimpan di dalam cakram keras dalam bentuk file teks. Program Python harus membuka file-file tersebut terlebih dahulu, mengekstrak teks di dalamnya baris demi baris, melakukan pembersihan teks, sebelum akhirnya data dikonversi menjadi representasi vektor numerik untuk dilatih oleh model.

Latihan Kecil dengan Contoh Jawaban

Tuliskan program yang membuat berkas bernama token.txt dan menulis kata "Fellowship" di dalamnya, kemudian baca kembali berkas tersebut dan tampilkan isinya. Contoh Jawaban:

with open("token.txt", "w") as f:
    f.write("Fellowship")

with open("token.txt", "r") as f:
konten = f.read()
print(konten)
