Struktur Data Koleksi

List, Tuple, Dictionary, dan Set untuk menyimpan data AI secara tepat.

Tujuan Chapter

Peserta menguasai karakteristik List, Tuple, Dictionary, dan Set, lalu mampu memilih struktur yang sesuai untuk menyimpan dataset, metadata, konfigurasi model, dan token unik.

Kenapa Topik Ini Penting untuk AI

Dalam AI, kita hampir tidak pernah bekerja dengan satu nilai tunggal. Kita menyimpan daftar file gambar, label kelas, konfigurasi hyperparameter, riwayat akurasi, vocabulary teks, dan metadata dataset. Struktur data yang salah membuat kode sulit dibaca, rawan error, dan lambat saat data membesar.

Konsep Utama

List adalah koleksi berurutan dan mutable. Elemen bisa ditambah, dihapus, atau diubah. Cocok untuk batch data, daftar skor, nama file, dan urutan token.

Tuple mirip list tetapi immutable. Cocok untuk data yang seharusnya tidak berubah, seperti shape gambar (224, 224, 3), koordinat, atau konfigurasi tetap.

Dictionary menyimpan pasangan key-value. Cocok untuk metadata, profil sampel, dan hyperparameter karena data diakses lewat label yang jelas, bukan indeks angka.

Set menyimpan elemen unik. Cocok untuk deduplikasi label atau membuat vocabulary unik dari daftar kata.

TipeUrutanMutableAksesContoh AI
ListYaYaIndeksDaftar skor, file, batch
TupleYaTidakIndeksShape gambar

Analogi

List seperti antrean pelanggan yang bisa berubah. Tuple seperti menu yang sudah dicetak dan tidak boleh diubah. Dictionary seperti loker dengan nomor kunci. Set seperti daftar tamu unik: nama yang sama tetap dihitung satu kali.

Contoh Kode Utama

list_model = ["YOLO", "BERT", "ResNet"]
tuple_dimensi = (224, 224, 3)
dict_param = {"learning_rate": 0.01, "batch_size": 32}
set_token = {"nlp", "computer_vision", "nlp"}

print("List model:", list_model)
print("Dimensi gambar:", tuple_dimensi)
print("Learning rate:", dict_param["learning_rate"])
print("Token unik:", set_token)

Penjelasan: list menyimpan nama model secara berurutan, tuple menyimpan shape gambar yang aman dari perubahan, dictionary menyimpan konfigurasi model, dan set otomatis menghapus token duplikat.

Contoh Tambahan

1. Slicing List

angka = [10, 20, 30, 40, 50]
potongan = angka[1:4]
print(potongan)  # [20, 30, 40]

2. Dictionary dengan .get()

config = {"epochs": 100}
lr = config.get("learning_rate", 0.001)
print(lr)

3. Operasi Set

set_a = {"ai", "python", "data"}
set_b = {"python", "nlp", "data"}
print("Gabungan:", set_a.union(set_b))
print("Irisan:", set_a.intersection(set_b))

Common Mistakes

  1. Mengakses indeks pertama dengan list[1]. Python mulai dari indeks 0.
  2. Mencoba mengubah tuple: tuple_dimensi[0] = 128.
  3. Mengakses dictionary dengan key yang tidak ada tanpa .get().
  4. Mengira set menjaga urutan data seperti list.

Best Practices

  1. Gunakan list untuk data yang berubah.
  2. Gunakan tuple untuk data tetap.
  3. Gunakan dictionary untuk data berlabel.
  4. Gunakan set untuk deduplikasi.
  5. Pilih struktur data dari kebutuhan akses, bukan dari kebiasaan.

Latihan Kecil

Buat dictionary model_info dengan key nama, akurasi_history, dan optimum. Cetak akurasi pertama.

model_info = {
    "nama": "ResNet-50",
    "akurasi_history": [0.85, 0.88, 0.91],
    "optimum": True
}
print(model_info["akurasi_history"][0])

Ringkasan Chapter

List, tuple, dictionary, dan set adalah alat penyimpanan data utama Python. Menguasai perbedaannya membuat pipeline data AI lebih jelas, aman, dan mudah diperluas.
