NumPy dan Operasi Matriks

Fondasi komputasi numerik untuk AI: array, shape, vektorisasi, statistik, transpose, dan dot product.

Tujuan Chapter

Peserta mampu melakukan inisialisasi array multi-dimensi menggunakan NumPy, memahami konsep efisiensi komputasi berbasis vektorisasi, serta mengeksekusi operasi matriks dasar yang menjadi fondasi banyak model AI.

Kenapa Topik Ini Penting untuk AI

Model AI tidak melihat gambar, teks, atau suara seperti manusia. Di dalam komputer, semuanya berubah menjadi angka. Gambar menjadi matriks piksel, teks menjadi vektor token atau embedding, dan bobot model menjadi matriks parameter. NumPy adalah pintu pertama untuk memahami dunia angka tersebut sebelum peserta bertemu PyTorch, TensorFlow, scikit-learn, atau library machine learning lain.

Konsep Utama

NumPy menyediakan struktur ndarray, yaitu array multi-dimensi homogen yang jauh lebih efisien untuk operasi numerik dibanding list Python biasa. List Python fleksibel, tetapi fleksibilitasnya membuat operasi matematika besar lambat karena interpreter harus memeriksa elemen satu per satu.

Vektorisasi adalah cara mengekspresikan operasi pada banyak angka sekaligus tanpa loop Python manual. Saat kita menulis array * 2, NumPy menjalankan operasi pada semua elemen dengan backend native yang jauh lebih cepat.

Shape menunjukkan bentuk array. Array satu dimensi bisa berbentuk (5,), matriks dua dimensi bisa berbentuk (2, 3), dan data gambar bisa berbentuk (tinggi, lebar, channel). Mengecek shape adalah kebiasaan wajib sebelum operasi matriks.

Dot product atau perkalian matriks adalah operasi baris-kali-kolom. Ini bukan perkalian elemen satu per satu. Di NumPy, dot product dapat ditulis dengan operator @ atau fungsi np.dot().

Analogi

Menggunakan list Python murni untuk operasi angka besar seperti memeras 100 jeruk satu per satu dengan tangan. NumPy seperti mesin pemeras industri: semua jeruk diproses bersamaan dengan satu tombol. Kita menulis instruksi ringkas, mesin cepat di bawahnya yang bekerja.

Contoh Kode Utama: Statistik Array

import numpy as np

data = np.array([78, 92, 65, 88, 71])

print("Data:", data)
print("Shape:", data.shape)
print("Rata-rata:", data.mean())
print("Standar deviasi:", round(data.std(), 2))
print("Nilai tertinggi:", data.max())

Penjelasan: np.array(...) mengubah list menjadi array NumPy. Method .mean(), .std(), dan .max() menghitung statistik langsung pada seluruh array. Peserta tidak perlu menulis loop manual untuk menghitung satu per satu.

Contoh Tambahan 1: Vektorisasi

import numpy as np

harga = np.array([10000, 20000, 30000, 40000])
diskon = harga * 0.5

print("Harga awal:", harga)
print("Harga diskon:", diskon)

Operator * di sini mengalikan setiap elemen array dengan 0.5. Ini disebut operasi elemen-demi-elemen, bukan dot product.

Contoh Tambahan 2: Matriks dan Transpose

import numpy as np

matriks = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print("Shape awal:", matriks.shape)
print("Transpose:")
print(matriks.T)
print("Shape transpose:", matriks.T.shape)

matriks.T menukar baris menjadi kolom. Shape awal (2, 3) berubah menjadi (3, 2).

Contoh Tambahan 3: Dot Product

import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])
B = np.array([
    [5, 6],
    [7, 8]
])

hasil_dot = A @ B
hasil_elemen = A * B

print("Dot product:")
print(hasil_dot)
print("Perkalian elemen-demi-elemen:")
print(hasil_elemen)

Operator @ melakukan dot product matriks. Operator * melakukan perkalian elemen dengan elemen pada posisi yang sama. Perbedaan ini sangat penting karena banyak bug numerik AI berasal dari salah memahami dua operator tersebut.

Common Mistakes

  1. Mengira * adalah dot product. Untuk aljabar matriks gunakan @ atau np.dot().
  2. Tidak mengecek .shape sebelum operasi matriks, lalu terkena error dimensi.
  3. Menulis np.zeros(3, 4) padahal shape harus tuple: np.zeros((3, 4)).
  4. Masih menulis loop Python manual untuk operasi yang bisa divektorisasi.

Best Practices

  1. Selalu gunakan alias standar import numpy as np.
  2. Cetak .shape saat debugging data numerik.
  3. Gunakan vektorisasi untuk operasi array besar.
  4. Bedakan operasi statistik, operasi elemen-demi-elemen, dan operasi aljabar matriks.

Latihan Kecil

Buat dua array x = [1, 2] dan y = [3, 4]. Hitung dot product dengan np.dot(x, y) dan jelaskan hasilnya.

import numpy as np

x = np.array([1, 2])
y = np.array([3, 4])

hasil = np.dot(x, y)
print(hasil)  # (1 * 3) + (2 * 4) = 11
