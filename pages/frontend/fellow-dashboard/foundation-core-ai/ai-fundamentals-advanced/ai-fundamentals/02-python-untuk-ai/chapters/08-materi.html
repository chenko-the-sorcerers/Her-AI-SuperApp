Lambda Expression dan Generator Basics

Materi final Pemrograman Python untuk AI disajikan lengkap, rinci, dan bertahap dari fondasi bahasa sampai pintu gerbang data science.

Tujuan Chapter

Peserta mampu menyusun fungsi anonim sekali pakai menggunakan ekspresi Lambda dan menghemat konsumsi memori untuk aliran data besar menggunakan konsep Generator sederhana.

Konsep Utama

Lambda adalah fungsi tanpa nama yang ditulis dalam satu baris ekspresi tunggal. Generator adalah jenis fungsi khusus yang menghasilkan urutan nilai secara bertahap menggunakan kata kunci yield alih-alih mengembalikan semua nilai sekaligus di memori.

Analogi

  • Lambda Expression seperti Pena Sekali Pakai di bank. Anda hanya membutuhkannya untuk menandatangani satu slip formulir cepat, lalu Anda meninggalkannya begitu saja tanpa perlu menyimpannya di tempat pensil khusus.
  • Generator seperti Keran Dispenser Air. Jika membutuhkan 10 liter air untuk diminum sepanjang hari, Anda tidak perlu membawa ember raksasa 10 liter ke mana-mana. Cukup gunakan botol kecil, dan putar keran dispenser untuk mengeluarkan air hanya pada saat haus satu gelas demi satu gelas.

Penjelasan Teori Rinci

Seiring dengan semakin besarnya skala aplikasi kecerdasan buatan dan sains data yang kita bangun, teknik penulisan kode konvensional kadang tidak lagi efisien. Python menyediakan fitur pemrograman fungsional tingkat lanjut untuk menyiasati keterbatasan efisiensi penulisan dan memori.
Lambda Expression: Ditulis dengan kata kunci lambda, diikuti parameter, tanda titik dua, dan ekspresi tunggal yang langsung dievaluasi serta dikembalikan hasilnya. Sintaksis Lambda sangat minimalis karena tidak membutuhkan kata kunci def maupun pernyataan return. Karakteristik utama Lambda adalah ia tidak memiliki nama di ruang namespace program. Lambda biasanya digunakan sebagai argumen untuk fungsi tingkat tinggi yang menerima fungsi lain sebagai masukannya, seperti fungsi filter, sorting khusus, atau fungsi pemetaan data pada Pandas DataFrame.
Generator: Fungsi normal di Python akan menghitung semua nilai hasil kalkulasi, menyimpannya di dalam memori sebagai satu List besar, lalu mengembalikannya ke pemanggil. Namun, jika dataset Anda berisi jutaan baris dokumen teks, menyimpannya sekaligus dalam memori akan menyebabkan sistem kehabisan RAM. Generator mengatasi masalah ini dengan menerapkan prinsip evaluasi malas.
Generator dideklarasikan seperti fungsi biasa menggunakan def, namun alih-alih menggunakan return, ia menggunakan kata kunci yield. Ketika fungsi generator dipanggil, ia tidak langsung menjalankan kode di dalamnya. Ia hanya mengembalikan objek generator. Ketika program meminta nilai berikutnya (misalnya melalui fungsi next() atau perulangan for), generator akan berjalan hingga menemui baris yield, mengembalikan nilai tersebut, dan membekukan status eksekusinya di titik tersebut. Saat diminta nilai berikutnya lagi, generator melanjutkan eksekusi dari titik beku tersebut.

Perbandingan Memori (Return vs Yield):
Return (Konvensional): ==> Dimuat semua ke RAM sekaligus
Yield (Generator): ==> Hanya satu data di RAM, sisanya diproses bertahap sesuai permintaan

Contoh Kode Utama

kali_dua = lambda x: x \* 2

def generator_angka():
yield 1
yield 2

Penjelasan Kode Baris demi Baris

  • Baris 1: kali_dua = lambda x: x * 2 Membuat fungsi anonim Lambda yang menerima satu parameter x dan langsung mengembalikan hasil perkalian x * 2.6 Fungsi ini disimpan ke variabel referensi kali_dua agar bisa dipanggil.
  • Baris 3: def generator_angka(): Mendeklarasikan fungsi generator khusus menggunakan kata kunci def.
  • Baris 4: yield 1 Menyerahkan angka 1 ke program utama dan menjeda eksekusi fungsi generator.
  • Baris 5: yield 2 Ketika dipanggil kembali untuk kedua kalinya, generator melanjutkan dan menyerahkan angka 2.1

3 Contoh Tambahan

  1. Menggunakan Lambda bersama fungsi filter 6:

       list_loss = [0.8, 0.4, 0.9, 0.2]
   loss_kecil = list(filter(lambda x: x < 0.5, list_loss))
   print(loss_kecil)

Penjelasan baris demi baris:
* Baris 1: list_loss = [...] mendefinisikan list angka.
* Baris 2: loss_kecil =... memanggil fungsi filter() yang menyaring elemen list menggunakan ekspresi Lambda lambda x: x < 0.5.6 Hasil saringan dikonversi kembali menjadi List.
* Baris 3: print(loss_kecil) mencetak [0.4, 0.2].
2. Membuat Generator deret angka genap dinamis 1:

   def genap_generator(maks):
       n = 0
       while n < maks:
           yield n
           n += 2

for angka in genap_generator(5):
print(angka)

Penjelasan baris demi baris:
* Baris 1: def genap_generator(maks): mendeklarasikan generator.
* Baris 3: while n < maks: mengevaluasi batas perulangan.
* Baris 4: yield n mengeluarkan angka genap aktif dan menjeda fungsi.
* Baris 5: n += 2 menaikkan nilai variabel untuk putaran berikutnya.
* Baris 7: for angka in... melintasi generator, menghasilkan output cetak 0 dan 2 secara bertahap.

3 Common Mistakes

  1. Mencoba Menulis Banyak Baris Logika di Dalam Lambda: Memaksakan percabangan atau perulangan di dalam ekspresi Lambda. Ingat bahwa Lambda dirancang hanya untuk menampung ekspresi satu baris tunggal.
  2. Menggunakan Generator yang Sudah Habis: Berusaha membaca ulang elemen dari generator yang sudah selesai dilintasi. Generator hanya bisa dibaca satu kali melintas; jika ingin dibaca ulang, Anda harus menginstansiasi ulang objek generator baru dari fungsinya.
  3. Mengasumsikan Generator Menyimpan Data Secara Fisik: Mengira bahwa objek generator adalah sebuah list yang bisa diperiksa panjangnya menggunakan fungsi len(). Hal ini akan langsung memicu TypeError karena generator tidak memiliki konsep ukuran panjang sebelum dievaluasi secara tuntas.

3 Best Practices

  1. Gunakan Lambda Expression hanya untuk fungsi pemrosesan satu baris yang sangat sederhana dan dilewatkan sebagai argumen fungsi pemetaan pustaka seperti Pandas atau Map.
  2. Gunakan Generator jika perlu memproses berkas teks besar, logs sistem raksasa, atau batch gambar berukuran gigabyte untuk menghemat kapasitas RAM komputer.
  3. Tuliskan dokumentasi yang jelas pada generator Anda untuk mempermudah developer lain memahami format batch data yang dikeluarkan di setiap putaran yield.1

Hubungan Konsep Ini dengan AI/Data Science

Pelatihan model pembelajaran mendalam modern tidak mungkin dilakukan tanpa generator. Dataset gambar medis atau teks internet raksasa berukuran ratusan gigabyte tidak akan muat di memori komputer. Dengan menggunakan generator (diimplementasikan sebagai DataLoader di PyTorch atau Data Generator di TensorFlow), model dapat mengambil gambar bertahap 32 per 32 gambar untuk dilatih, membebaskan memori RAM agar program tetap berjalan stabil.

Latihan Kecil dengan Contoh Jawaban

Buatlah ekspresi Lambda bernama is_positive yang menerima satu parameter angka dan mengembalikan nilai True jika angka tersebut lebih besar dari nol, dan False jika sebaliknya. Contoh Jawaban:

is_positive = lambda x: x > 0
print(is_positive(5))
print(is_positive(-3))

Ringkasan Chapter
