  ## SOURCE-AS-MAIN CONTRACT

  - Source chapter canonical adalah isi utama dan tidak boleh diubah untuk styling.
  - Jangan menghapus, meringkas, mengacak urutan, atau mengganti source dengan visual.
  - Controller boleh memfilter heading module-level yang benar-benar duplikat, strip numbering heading, wrap visual elements, dan inject enrichment.
  - Visual/enrichment harus muncul dekat konsep terkait, bukan ditumpuk semuanya di akhir.
  - Tandai node injected agar audit integritas dapat membedakannya.
  - Bandingkan normalized `textContent` sebelum/sesudah transformasi.
  - Pindahkan interactive DOM memakai `appendChild(node)`, bukan `cloneNode(true)`.
  - Gunakan request token atau `AbortController` supaya fetch chapter lama tidak menimpa chapter terbaru.

  ## FLOW MATERI UNTUK PEMULA

  Setiap topik final harus terasa terarah:

  ## CRITICAL TECHNICAL RULES

  1. Semua `sourcePath` adalah absolute FULL PATH yang nyata. Jangan pernah pakai literal `/pages/.../`.

  2. `CHAPTERS` minimal punya:
     `title`, `shortTitle`, `duration`, `icon`, `summary`, `objectives`, `sourcePath`.

  3. Setiap `PRACTICES` entry wajib punya:
     `fields: [["jawaban", "Tulis jawabanmu di sini..."]]`.

  4. First-visit practice wajib aman:
     `const saved = getSavedPractice() || { answers: {}, revealed: [] };`

  5. `PRACTICE_TOPICS`, labels, copy HTML, storage namespace, dan icon harus milik course baru—bukan sisa Reasoning/Python/Modern.

  6. Audit capability/function parity dari Reasoning, minimal:
     `renderList`, `renderFlow`, `escapeHtml`, `escapeSelector`, `safeJsonParse`, `setStatus`, `findH2Sections`, semua `finalRender*`, `renderSourceVisualLab`, `initSourceVisualLab`, `enhanceSourceMaterialForCanvas`, semua `setup*`, `filterSourceHeadings`, `stripSourceNumbering`, `injectAfterHeading`, `renderFormattedText`, `renderPracticeCard`, `loadSourceHtml`, `getSourceFile`.

  7. Nama `window.init...` controller harus persis sama dengan yang diperiksa router.

  8. `index.html` wajib memuat controller baru.

  9. File activity belum berarti route activity final. Route, initializer, data, interaction, dan QA semuanya harus aktif.

  10. Jangan mengubah localStorage keys existing tanpa migrasi backward-compatible.

  ## HERAI UI RULES

  - Light learning surface: putih, `#fff7fb`, `#fff0f7`, atau `#fffcfd`.
  - Text utama `#171827`; secondary minimal `#6f7282`.
  - Pink `#f63392` sebagai accent utama.
  - Tidak ada visible `border-radius: 0`.
  - Card/container 14–20px; button/pill 100px; input 14–20px; code 12–16px; icon circle 50%.
  - Tidak ada emoji di UI; gunakan FontAwesome.
  - Tidak ada default browser button/input untuk aksi utama.
  - Jangan grid/flex langsung paragraph mixed text node + inline element. Bungkus text.
  - Audit global source selectors agar tidak menimpa objective/checklist/component-specific markers.
  - Tidak boleh ada text pecah satu kata/huruf per baris.

  ## ERROR HISTORY YANG WAJIB DICEGAH

  - CSS block hilang sesudah merge walau JS masih ada.
  - Renderer class tidak sama dengan selector CSS.
  - JS memakai `active/complete`, CSS mengharap `is-active/is-complete`.
  - Helper function terlewat saat copy controller.
  - Literal `...` pada source path menyebabkan 404.
  - Missing `fields` dan null storage membuat practice crash.
  - Router initializer mismatch atau script index hilang.
  - Guide/pagination jatuh ke browser default.
  - Textarea/lab/objective rusak karena grid/pseudo-element global.
  - Quiz map berada setelah question.
  - Chapter fetch race.
  - Cache JS/CSS tidak dibump bersama.
  - `scrollWidth` lulus tetapi isi card tetap tidak terbaca; screenshot tetap wajib.
  - Quiz masih pakai `reasoning-q` bukan `python-q` — sudah fixed.
  - Worked example nomor tidak center — sudah fixed (CSS counter badges).
